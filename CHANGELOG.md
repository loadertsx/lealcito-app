# Changelog

## 0.0.3

### Changed

- Reorganize the application into `routes`, `features`, `core`, and `shared`.
- Group authentication, businesses, and loyalty schemas, queries, mutations,
  and components by feature.
- Centralize database access, email transport, and same-origin protection in `core`.
- Move the welcome template alongside its route and remove the legacy services layer.
- Preserve existing URLs, database definitions, and migration history.

### Added

- Architecture documentation describing feature ownership and dependency boundaries.
- Tests for authentication origin checks and session cookie behavior.

## 0.0.2

### Added

- Add initial database models

## [0.0.1]

### Added

- Initial application setup with React 19, React Router, and TypeScript.
- Server-side rendering and Cloudflare Workers deployment configuration.
- Tailwind CSS styling and Vite development tooling.
- Biome configuration for linting and formatting.
- Scripts for development, production builds, deployment, and type checking.
- Cloudflare D1 setup with a shared `DB` binding for local, staging (`lealcito-stg`)
  and production (`lealcito-prod`), a `database/migrations/` directory, and `db:*` scripts.
- Drizzle ORM as the data model and query builder: schema in `database/schema.ts`,
  client in `database/client.ts`, migrations generated by Drizzle Kit and applied
  with Wrangler.
