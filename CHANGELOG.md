# Changelog

## [0.0.1]

### Added

- Initial application setup with React 19, React Router, and TypeScript.
- Server-side rendering and Cloudflare Workers deployment configuration.
- Tailwind CSS styling and Vite development tooling.
- Biome configuration for linting and formatting.
- Scripts for development, production builds, deployment, and type checking.
- Cloudflare D1 setup with a shared `DB` binding for local, staging (`lealcito-stg`)
  and production (`lealcito-prod`), a `migrations/` directory, and `db:*` scripts.
- Drizzle ORM as the data model and query builder: schema in `database/schema.ts`,
  client in `database/client.ts`, migrations generated by Drizzle Kit and applied
  with Wrangler.
